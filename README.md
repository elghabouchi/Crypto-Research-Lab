# Crypto Research Lab

A research-oriented repository dedicated to cryptography, provable security, cryptographic protocols, and modern security constructions.

## Objective

This repository documents my work as an MSc student in Cryptography & Information Security.

The primary goal is not only to implement cryptographic constructions, but also to understand their mathematical foundations, security assumptions, and formal security properties.

## Research Interests

### Provable Security

* Security Games
* IND-CPA
* IND-CCA
* EUF-CMA
* PRFs and PRPs
* Security Reductions

### Cryptographic Protocols

* Identification Protocols
* Digital Signatures
* Key Exchange Protocols
* Commitment Schemes

### Zero-Knowledge Proofs

* Schnorr Identification
* Fiat-Shamir Transform
* Sigma Protocols
* Modern ZK Systems

### Post-Quantum Cryptography

* ML-KEM (Kyber)
* ML-DSA (Dilithium)
* Lattice-Based Cryptography
* PQC Security Concepts

### Blockchain Security Foundations

* Merkle Trees
* Cryptographic Commitments
* Signature Schemes
* Security Assumptions Behind Blockchain Protocols

## Methodology

For every topic:

1. Study the theoretical foundations.
2. Read academic references.
3. Implement a minimal educational version when appropriate.
4. Analyze security assumptions.
5. Produce technical notes and reports.
